# Dhaman Implementation Phases

## Phase 0

Project infrastructure, Prisma, config, common types, CLS/request context, error translator, common exception filters, module shells.

## Phase 1

Auth, Users, Clients.

## Phase 2

Agreements, Policies, Milestones.

## Phase 3

Payments simulation, Deliveries, Timeline.

## Phase 4

Client Portal.

## Phase 5

AI Plan, AI Review, Change Requests.

## Phase 6

Email Notifications, Dashboard Analytics, Settings.

## Phase 7

Frontend Integration.

## Stop Rule

After completing each phase, stop and ask:

`Phase X is complete. Do you want me to proceed to Phase X+1?`

Before Phase 7 implementation, stop and ask:

`Is the frontend ready for integration?`
